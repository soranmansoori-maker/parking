با cmd  به مسیر پروژه برین

به مسیر بکند برین 
اول دستور npm install را اجرا کنید


بعد به مسیر فرانت برید به ترتیب دستور های زیر را اجرا کنید

npm install sqlite3 --build-from-source=false

npm install




بعد اجرای دستورات بالا
به مسیر بکند بروید و دستور npm start را وارد و اجرا کنید

و بعد به مسیر فرانت بروید و دستور npm run dev  را وارد و اجرا کنید

بعد این دستورات گوگل کروم را باز کرده و ادرس localhost:3000 را وارد کرده  و پروژه رو مشاهده فرمایید
